🌍 Urban Risk Map: Multi-Hazard Geospatial Dashboard
📌 Project Overview
The Urban Risk Map is an interactive geospatial intelligence tool designed to track and visualize multi-hazard risks in urban environments. Utilizing Python, Folium, and Geopandas, this dashboard provides data-driven insights into regional vulnerabilities, helping stakeholders identify high-risk zones for better disaster preparedness and urban planning.

Status: 🚧 Work in Progress. This repository is currently being updated with real-time data integration and enhanced risk modeling logic.

🚀 Key Features
Interactive Risk Visualization: Dynamic maps using Folium to overlay risk zones.

Geospatial Analysis: Processing spatial data with Geopandas for accurate boundary mapping.

Multi-Hazard Tracking: Designed to visualize various risks (e.g., flood, fire, or seismic activity).

User-Friendly UI: Built with Streamlit for a seamless, browser-based experience.

🛠️ Tech Stack
Language: Python

Libraries: Streamlit, Folium, Geopandas, Pandas, NumPy

Mapping: OpenStreetMap / Leaflet
📂 Installation & Setup

2.Create a virtual environment:

source venv/bin/activate  # On Windows: venv\Scripts\activate
